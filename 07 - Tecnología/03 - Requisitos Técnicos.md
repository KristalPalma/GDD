# Requisitos Técnicos

## Descripción de la sección

Define las condiciones técnicas necesarias para ejecutar y desarrollar el videojuego.

## Requisitos mínimos

**Sistema operativo:** Windows 10 de 64 bits.

**CPU:** Procesador de 64 bits con soporte para SSE2.

**GPU:** Tarjeta gráfica integrada o dedicada compatible con DirectX 11.

**RAM:** 4 GB.

**Almacenamiento:** 200 MB de espacio libre.

**Resolución:** 1280×720.

**Conexión:** No requerida.

## Requisitos recomendados

**Sistema operativo:** Windows 11 de 64 bits.

**CPU:** Procesador de 64 bits de cuatro núcleos.

**GPU:** Tarjeta gráfica compatible con DirectX 12.

**RAM:** 8 GB.

**Almacenamiento:** 200 MB de espacio libre.

## Objetivos de rendimiento

**FPS objetivo:** 60 FPS.

**Tiempo de carga objetivo:** Menos de 5 segundos al cambiar de escena.

**Memoria máxima:** Dentro de los 4 GB de RAM de los requisitos mínimos.

## Restricciones

Documenta límites conocidos del proyecto.

- **Plataforma:** el juego se compila únicamente para Windows de 64 bits.
- **Motor:** el proyecto utiliza Unity 6 (versión 6000.6.3f1) con Universal Render Pipeline 2D. Todo el equipo debe abrirlo con esta misma versión para evitar conflictos.
- **Entrada:** teclado y ratón. No hay soporte para mando ni controles táctiles, y las teclas no pueden reasignarse.
- **Resolución:** la interfaz se diseñó con una referencia de 1920×1080 (16:9) y se escala según la altura de la pantalla.
- **Guardado:** una sola ranura de guardado automático.
- **Idioma:** español.
- **Conexión:** el juego funciona sin conexión a internet.
